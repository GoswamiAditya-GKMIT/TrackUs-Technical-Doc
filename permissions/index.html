    Permissions & Access Control

    TrackUs employs a robust Role-Based Access Control (RBAC) system with five distinct roles (three global and two implicit roles).

    Roles & Permissions Matrix

    The following table outlines the permissions for each role within TrackUs.

    Action Super Admin Tenant Admin Normal User Rules / Notes
    Create Tenant Yes No No Only Super Admin can onboard new organization (Tenants).
    Deactivate Tenant Yes No No Deactivation blocks all login access for that organization.
    Create Tenant Admin Yes No No Must specify target Tenant.
    Delete Tenant Admin Yes No No Only the platform owner can manage organization admins.
    Create User No Yes No Tenant Admin can only create users in their own Tenant.
    Update/Delete User Yes Yes Yes (Self) Tenant Admin manages their org users. Users update own profile.
    Create Group No Yes Yes Any user can create a travel group (becomes Group Admin).
    View Group (Active) No Yes (All) Yes (Joined) Users see groups they are members of. Tenant Admins see all in tenant.
    Update Group No Yes Yes (Admin) Only Group Admins or Tenant Admins can update group details.
    Delete Group No Yes Yes (Admin) Soft-deletion only.
    Add Member No Yes Yes (Admin) Invitation to join the group.
    Create Event No Yes Yes (Admin) Events are added to groups by Group Admins.
    View Event No Yes (All) Yes (Joined) Users see itinerary for their groups.
    Update Event No Yes Yes (Admin) Only Group Admins can modify the itinerary.
    Delete Event No Yes Yes (Admin) Soft-deletion or cancellation.
    Live Location No No Yes (Joined) Strictly limited to participants of the active group.
    Group Chat (Send) No Yes (Admin) Yes (Joined) Members can send messages to their groups.
    Group Chat (View) No Yes (All) Yes (Joined) History accessible to all current members.
    Event Chat (Send) No Yes (Admin) Yes (Participant) Only accepted participants can chat in events.
    Event Chat (View) No Yes (All) Yes (Participant) History accessible to participants.
    Manage Participants No Yes Yes (Admin) Add/Remove participants from events.
    Accept/Reject Invite No Same as User Yes Users must explicitly accept event invitations.
    Leave Group No N/A Yes Members can leave at any time (unless sole admin).
    Leave Event No Same as User Yes Participants can leave events they previously accepted.
    View Location History No Yes (All) Yes (Joined) Paths and trails are recorded for the duration of the event.
    Simulate Location No No Yes (Dev Mode) Feature for testing location updates (if enabled).
